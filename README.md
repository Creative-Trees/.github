# `.github` — Berkas Default Komunitas & Organisasi Creative Trees

Repositori khusus ini menggerakkan **halaman profil organisasi** Creative Trees dan menjadi
sumber **berkas kesehatan komunitas default** serta **template alur kerja (workflow)** yang
otomatis diwariskan ke repositori lain yang belum memiliki versinya sendiri.

## Isi repositori ini

| Berkas / Folder | Fungsi |
|---|---|
| `profile/README.md` | Konten yang tampil di halaman profil github.com/Creative-Trees. |
| `CODE_OF_CONDUCT.md` | Aturan perilaku bagi siapa pun yang berinteraksi di repositori Creative Trees. |
| `CONTRIBUTING.md` | Panduan berkontribusi: alur branch, commit, dan pull request. |
| `SECURITY.md` | Cara melaporkan kerentanan keamanan secara privat. |
| `SUPPORT.md` | Cara mendapatkan bantuan atau mengajukan pertanyaan. |
| `GOVERNANCE.md` | Peran, tanggung jawab, dan cara pengambilan keputusan tim. |
| `CODEOWNERS` | Peninjau otomatis untuk perubahan pada repositori ini. |
| `ISSUE_TEMPLATE/` | Formulir issue terstruktur: laporan bug & usulan fitur. |
| `PULL_REQUEST_TEMPLATE.md` | Checklist standar setiap pull request. |
| `workflow-templates/` | Template CI siap pakai untuk proyek Laravel/PHP dan Node/Svelte. |

## Kenapa ini penting

Berkas-berkas di atas berlaku otomatis untuk setiap repositori Creative Trees yang belum
mempunyai versinya sendiri — ini adalah fitur *default community health file* bawaan GitHub.
Dengan begitu, setiap proyek baru langsung punya standar kontribusi, pelaporan bug, dan
keamanan yang konsisten tanpa perlu disiapkan ulang dari nol.
